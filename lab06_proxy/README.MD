## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Кнопки «Очистить», «Сбросить сохранённый пароль».
- Демонстрация паттерна **«Заместитель»** — класс `PasswordManagerProxy` оборачивает реальный `PasswordManager` и добавляет:
  - **ленивую инициализацию** (реальный сервис создаётся только при первом обращении);
  - **защиту от подбора** (блокировка после 5 неверных попыток на 30 секунд);
  - **логирование** всех операций;
  - **контроль доступа** (счётчик неудачных попыток отображается в интерфейсе).

## Паттерн «Заместитель»

Паттерн «Заместитель» (Proxy) — это структурный паттерн, который подставляет другой объект вместо реального сервиса и контролирует доступ к нему. Заместитель имеет тот же интерфейс, что и реальный объект, поэтому клиент не замечает подмены.

В программе определены роли:

- `PasswordService` — общий интерфейс (Subject);
- `PasswordManager` — реальный сервис (RealSubject), Singleton с хэшированием;
- `PasswordManagerProxy` — заместитель (Proxy).

`PasswordManagerProxy` реализует тот же интерфейс `PasswordService` и добавляет:

- **Ленивую инициализацию** — `PasswordManager` создаётся только при первом вызове, а не при старте приложения;
- **Ограничение попыток** — после 5 неверных попыток вход блокируется на 30 секунд;
- **Логирование** — все вызовы записываются в лог с меткой времени и уровнем;
- **Счётчик попыток** — UI может запросить `get_failed_attempts()`.

Кнопка «Показать лог прокси» демонстрирует, как заместитель фиксирует все обращения к реальному сервису.
