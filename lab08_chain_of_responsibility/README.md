## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Панель шаблонов («Крест», «Квадрат», «Зигзаг»).
- Кнопка «Проверить цепочкой» — запускает валидацию последовательности через цепочку обработчиков.
- Демонстрация паттерна **«Цепочка обязанностей»** — валидация пароля разбита на независимые обработчики, связанные в цепочку.

## Паттерн «Цепочка обязанностей»

Паттерн «Цепочка обязанностей» (Chain of Responsibility) — это поведенческий паттерн, который позволяет передавать запрос последовательно по цепочке обработчиков. Каждый обработчик решает, обработать запрос самому или передать его дальше.

В программе определены роли:

- `SequenceValidator` — абстрактный обработчик с методами `set_next()` и `handle()`;
- `LengthValidator` — проверяет длину (4–9);
- `DuplicateValidator` — проверяет отсутствие повторов;
- `RangeValidator` — проверяет, что все ячейки в диапазоне 1–9;
- `SimplePatternValidator` — отклоняет слишком простые пароли (с одинаковым шагом);
- `ValidationChain` — удобная обёртка, собирающая цепочку.

Порядок цепочки: **Длина → Повторы → Диапазон → Простота**.

Если обработчик находит ошибку — он возвращает `ValidationResult(False, message)` и **прерывает** цепочку. Если ошибки нет — передаёт запрос следующему обработчику. Если все обработчики вернули `None`, последовательность считается корректной.

## Основные классы

| Элемент | Назначение |
|---|---|
| `ValidationResult` | Результат проверки (valid, message) |
| `SequenceValidator` | Абстрактный обработчик цепочки |
| `LengthValidator` | Проверка длины |
| `DuplicateValidator` | Проверка повторов |
| `RangeValidator` | Проверка диапазона |
| `SimplePatternValidator` | Проверка «простоты» пароля |
| `ValidationChain` | Обёртка для сборки цепочки |
| `PasswordPattern` | Шаблон пароля |
| `PasswordManager` | Singleton с хэшированием |
| `AppWindow` | Основной класс интерфейса |

---

Содержит:
- `SequenceValidator` и его наследников (`LengthValidator`, `DuplicateValidator`, `RangeValidator`, `SimplePatternValidator`);
- `ValidationChain` — обёртка для цепочки;
- `AppWindow`, `PasswordManager`, `PasswordPattern` — основные классы приложения.
