## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Панель шаблонов («Крест», «Квадрат», «Зигзаг»).
- Кнопка «Очистить», «Сбросить сохранённый пароль».
- Демонстрация паттерна **«Фасад»** — весь UI работает через `PasswordFacade`, не обращаясь к `PasswordManager` напрямую.
- Демонстрация паттерна **«Приспособленец»** — стили ячеек (`CellStyle`) кэшируются и разделяются между всеми 9 ячейками (кнопка «Статистика Flyweight»).

## Паттерн «Фасад»

Паттерн применён для упрощения работы с подсистемой пароля. Класс `PasswordFacade` скрывает:

- `PasswordManager` (Singleton с хэшированием);
- список шаблонов `PasswordPattern`;
- валидацию последовательности;
- работу с файлом `graphical_password.json`.

UI вызывает только простые методы:

```python
result, message = self.facade.create_password(self.selected)
result, message = self.facade.verify(self.selected)
self.facade.reset()
self.facade.has_password()
self.facade.get_patterns()
