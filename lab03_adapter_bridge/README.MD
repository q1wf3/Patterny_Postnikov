## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек (от 1 до 9).
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Кнопки «Очистить», «Сбросить сохранённый пароль».
- Демонстрация паттерна **«Адаптер»** — кнопка «Показать строку (Адаптер)» преобразует внутренний список чисел в строку с разделителями.
- Демонстрация паттерна **«Мост»** — переключение режимов отрисовки связей между выбранными ячейками («Простой» / «С линиями»).

## Паттерн «Адаптер»

Паттерн применён для преобразования внутренней последовательности пароля (списка чисел) в строковый формат и обратно.

Классы:

- `SequenceTarget` — целевой интерфейс с методами `get_sequence_string()` и `set_sequence_from_string(data)`;
- `ListAdaptee` — адаптируемый класс, хранящий последовательность в виде списка чисел;
- `SequenceAdapter` — адаптер, преобразующий список `[1, 5, 9, 8]` в строку `"1-5-9-8"` и обратно.

```python
class SequenceAdapter(SequenceTarget):
    def __init__(self, adaptee: ListAdaptee):
        self._adaptee = adaptee

    def get_sequence_string(self) -> str:
        return "-".join(map(str, self._adaptee.get_list()))

    def set_sequence_from_string(self, data: str):
        if not data:
            self._adaptee.set_list([])
            return
        parts = data.split("-")
        self._adaptee.set_list([int(p) for p in parts])
