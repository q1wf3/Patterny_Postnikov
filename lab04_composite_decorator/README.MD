# Лабораторная работа №4 — Структурные паттерны: Компоновщик, Декоратор

**Тема:** Структурные паттерны проектирования: Компоновщик (Composite), Декоратор (Decorator)  
**Паттерны:** Компоновщик (Composite), Декоратор (Decorator)  
**Вариант 8:** Графический пароль

---

## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Кнопки «Очистить», «Сбросить сохранённый пароль».
- Демонстрация паттерна **«Компоновщик»** — шаблон «Набор» состоит из нескольких простых шаблонов и применяет их объединённую последовательность.
- Демонстрация паттерна **«Декоратор»** — шаблоны «★ Крест» (избранное) и «⇄ Квадрат» (реверс) оборачивают базовый шаблон и добавляют новое поведение.

---

## Паттерн «Компоновщик»

Паттерн применён для группировки шаблонов. Базовый интерфейс `PasswordComponent` реализуют:

- `PasswordLeaf` — простой шаблон (одна последовательность);
- `PasswordComposite` — группа шаблонов («Набор»). При применении объединяет последовательности детей, удаляет дубликаты и обрезает до 9 элементов.

Пример: «Набор: Крест + Квадрат» объединяет `[2, 5, 8, 4, 6]` и `[1, 2, 3, 6, 9, 8, 7, 4]` в `[2, 5, 8, 4, 6, 1, 3, 9, 7]`.

---

## Паттерн «Декоратор»

Паттерн применён для расширения шаблонов без изменения их кода:

- `PatternDecorator` — базовый декоратор, оборачивающий `PasswordComponent`;
- `FavoriteDecorator` — добавляет префикс «★ » к имени;
- `ReversedDecorator` — переворачивает последовательность и добавляет префикс «⇄ ».

Декораторы работают прозрачно: клиентский код вызывает `get_name()` и `get_sequence()`, не зная, обёрнут ли компонент.
