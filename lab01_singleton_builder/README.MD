## Лабораторная работа №1 — Порождающие паттерны: Одиночка

**Тема:** Порождающие паттерны проектирования: Одиночка (Singleton)  
**Паттерн:** Одиночка (Singleton)  
**Вариант 8:** Графический пароль

### Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти ячеек (от 1 до 9).
- Два режима: **создание пароля** и **вход**.
- Требования к паролю:
  - длина последовательности от 4 до 9 ячеек;
  - одна и та же ячейка не может быть выбрана повторно;
  - выбранные ячейки отображаются в текущей последовательности.
- Хранение пароля в файле `graphical_password.json` **в виде SHA-256 хэша** (не в открытом виде).
- Проверка пароля путём сравнения хэшей.
- Удаление сохранённого пароля.
- Кнопки «Очистить» (сброс текущей последовательности) и «Сбросить сохранённый пароль».

### Паттерн Singleton

Паттерн применён к классу `PasswordManager`. Класс отвечает за создание, сохранение, проверку и удаление графического пароля.

Реализация:

```python
class PasswordManager:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance
