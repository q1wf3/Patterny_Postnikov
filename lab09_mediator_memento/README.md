## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Панель шаблонов («Крест», «Квадрат», «Зигзаг»).
- Кнопка **«↶ Отменить (снимок)»** — откатывает состояние к предыдущему снимку.
- Демонстрация паттерна **«Посредник»** — все компоненты UI (сетка, кнопки, метки) общаются только через `UIMediator`, не обращаясь друг к другу напрямую.
- Демонстрация паттерна **«Снимок»** — `SequenceCaretaker` хранит историю снимков состояния (`SequenceMemento`) и позволяет откатываться по стеку.

---

## Паттерн «Посредник»

Паттерн «Посредник» (Mediator) — это поведенческий паттерн, который убирает прямые связи между компонентами, заставляя их общаться через единый объект-посредник.

В программе определены роли:

- `UIMediator` — посредник, координирующий работу всех компонентов;
- `GridComponent` — сетка ячеек (не знает о кнопках и метках);
- `RoundedButton` — кнопки (не знают о сетке);
- `tk.Label` — метки (не знают ни о чём).

Каждый компонент при событии вызывает `mediator.notify(self, "event", data)`, а посредник решает, что делать и кого обновить. Это устраняет прямые зависимости между UI-компонентами.

Обрабатываемые события:
- `cell_clicked` — клик по ячейке;
- `mode_changed` — переключение режима;
- `clear` — очистка;
- `primary_action` — основное действие;
- `undo` — откат к предыдущему снимку;
- `pattern_clicked` — клик по шаблону;
- `reset_password` — сброс пароля.

---

## Паттерн «Снимок»

Паттерн «Снимок» (Memento) — это поведенческий паттерн, который позволяет сохранить и восстановить внутреннее состояние объекта, не нарушая инкапсуляцию.

В программе определены роли:

- `SequenceMemento` — снимок состояния (выбранная последовательность + режим);
- `SequenceCaretaker` — хранитель истории снимков;
- `AppWindow` — объект-источник (создаёт и восстанавливает состояние).

При каждом действии (выбор ячейки, переключение режима, очистка, применение шаблона) `UIMediator` сохраняет новый снимок через `caretaker.save(...)`. При нажатии «↶ Отменить (снимок)» вызывается `caretaker.undo()`, который возвращает предыдущий снимок и восстанавливает состояние.

## Основные классы

| Элемент | Назначение |
|---|---|
| `UIMediator` | Посредник для всех UI-компонентов |
| `GridComponent` | Сетка ячеек (общается через посредника) |
| `SequenceMemento` | Снимок состояния (последовательность + режим) |
| `SequenceCaretaker` | Хранитель истории снимков |
| `PasswordPattern` | Шаблон пароля |
| `PasswordManager` | Singleton с хэшированием |
| `AppWindow` | Основной класс приложения |

---

## Диаграмма классов

Содержит:
- `UIMediator` — посредник;
- `GridComponent`, `RoundedButton` — компоненты, общающиеся через посредника;
- `SequenceMemento`, `SequenceCaretaker` — снимок и хранитель;
- `AppWindow`, `PasswordManager`, `PasswordPattern` — основные классы.
