# Лабораторная работа №12 — Архитектурные паттерны: MVC

**Тема:** Архитектурные паттерны проектирования: MVC (Model-View-Controller)  
**Паттерн:** MVC (Model-View-Controller)  
**Вариант 8:** Графический пароль

---

## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter, построенное по архитектурному паттерну **MVC**:

- **Model** (`PasswordModel`) — хранит состояние (выбранные ячейки, хэш пароля) и содержит бизнес-логику (создание, проверка, сброс пароля, сохранение в JSON).
- **View** (`PasswordView`) — отвечает только за отображение: сетка, кнопки, метки, диалоги. Не содержит логики.
- **Controller** (`PasswordController`) — связывает Model и View: обрабатывает события UI, вызывает методы Model, обновляет View.

Функционал:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Кнопки «Очистить», «Сбросить сохранённый пароль».

---

## Паттерн MVC

**Model** (`PasswordModel`):

- Хранит `_selected` и `_password_hash`.
- Методы: `select_cell()`, `clear()`, `has_password()`, `create_password()`, `verify_password()`, `reset_password()`.
- Не знает ничего о Tkinter и UI.

**View** (`PasswordView`):

- Строит интерфейс (`build()`).
- Метод `render(selected, mode, status_text, status_color)` обновляет отображение.
- Делегирует события в Controller через `self.controller.on_*()`.
- Не содержит бизнес-логики — только отрисовка и диалоги.

**Controller** (`PasswordController`):

- Обрабатывает события: `on_cell_clicked`, `on_clear`, `on_mode_changed`, `on_primary_action`, `on_reset_password`.
- Вызывает методы Model, обновляет View через `_refresh()`.

Преимущества такой архитектуры:
- Логика отделена от UI — можно заменить Tkinter на другую библиотеку, не трогая Model.
- View можно переиспользовать, Controller становится проще для тестирования.
- Чёткое разделение ответственности.
