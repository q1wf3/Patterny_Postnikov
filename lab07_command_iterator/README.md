## Что реализовано

Приложение «Графический пароль» на Python с использованием Tkinter:

- Сетка 3×3 из девяти скруглённых ячеек.
- Формирование последовательности графического пароля.
- Сохранение пароля в виде SHA-256 хэша в файл `graphical_password.json`.
- Проверка пароля путём сравнения хэшей.
- Два режима: **создание пароля** и **вход**.
- Демонстрация паттерна **«Команда»** — все действия (выбор ячейки, очистка, применение шаблона) выполняются через объекты-команды. Реализованы **отмена** (`↶ Отменить`) и **повтор** (`↷ Повторить`).
- Демонстрация паттерна **«Итератор»** — навигация по коллекции шаблонов кнопками `◀` / `▶` с отображением текущего шаблона и его позиции (`1/3`).

## Паттерн «Команда»

Паттерн «Команда» (Command) — это поведенческий паттерн, который инкапсулирует запрос в виде объекта, позволяя параметризовать клиентов командами, ставить их в очередь, логировать и поддерживать отмену операций.

В программе определены роли:

- `Command` — абстрактная команда с методами `execute()` и `undo()`;
- `SelectCellCommand` — команда выбора ячейки;
- `ClearSelectionCommand` — команда очистки последовательности;
- `ApplyPatternCommand` — команда применения шаблона;
- `CommandInvoker` — инициатор, хранящий историю команд и стек повторов.

Все действия пользователя проходят через `CommandInvoker.execute(...)`, что даёт возможность отмены и повтора:

```python
self.invoker.execute(SelectCellCommand(self, num))
self.invoker.execute(ClearSelectionCommand(self))
self.invoker.execute(ApplyPatternCommand(self, pattern))
