## Паттерн «Абстрактная фабрика»

Паттерн применён для создания элементов графического интерфейса. В программе есть абстрактная фабрика `PasswordFactory`, которая определяет методы создания элементов:

- `create_point(parent, number, command, selected)` — создание ячейки сетки;
- `create_button(parent, text, command)` — создание кнопки;
- `create_line(canvas)` — создание линии (для расширения);
- `get_colors()` — получение цветовой схемы.

На её основе реализованы две конкретные фабрики:

- `DarkPasswordFactory` — элементы для тёмной темы;
- `LightPasswordFactory` — элементы для светлой темы.

При переключении темы приложение меняет используемую фабрику:

```python
if isinstance(self.factory, DarkPasswordFactory):
    self.factory = LightPasswordFactory()
else:
    self.factory = DarkPasswordFactory()
